# 每日地圖路線狀態

大眾運輸保留 Google 參考路線，畫面持續標示可能與 TDX 班次不同；未宣稱已精確對齊。現有 TdxRoute/RouteSection 只保留站名、路線名稱、方向及時間，沒有路線 UID、站點座標或形狀；精確 TDX 繪圖需另行補足資料模型及來源。

每日每段分別載入。成功立即呈現；錯誤或空路徑只將該段標為失敗，繼續查後續路段。失敗段以紅色短虛線連起終點，明確標示非可行走道路。提供成功/失敗數量、查看原因及重試失敗路段。重試保留成功路徑。切換日期後不再派送舊批次尚未開始的路段；已送出的查詢不保證能取消。

大眾運輸出發時間若無效或超出現有程式範圍（目前時間前 7 天至後 100 天），JavaScript 直接回報原因，不省略日期改查其他時段。步行與無即時路況汽車維持無日期查詢。該範圍是目前程式採用的限制，不保證範圍內皆有班次。

驗證：Flutter 地圖平台替身測試中段失敗及局部重試；Node 測試有效日期原樣保留、無效/超界日期不送請求及步行汽車不受日期限制。未使用真實 Google 或 TDX 呼叫。
